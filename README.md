# Caddie releases

Installers for [Caddie](https://caddie.dev), the agent studio for CAD.

Download the latest build from [caddie.dev/download](https://caddie.dev/download) or the
[latest release](https://github.com/williamschill/caddie-releases/releases/latest):

| System | File |
| --- | --- |
| macOS, Apple Silicon | `Caddie-arm64.dmg` |
| macOS, Intel | `Caddie-x64.dmg` |
| Linux x64 | `Caddie-x86_64.AppImage` |
| Windows 10 / 11 | `Caddie-Setup-x64.exe` |

Caddie checks this repository for updates itself. Builds are published here automatically; the
source lives elsewhere, so please report issues through [caddie.dev](https://caddie.dev).
